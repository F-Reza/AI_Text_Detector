AI Detector API Documentation

Quick Start

GET STARTED
Example Request 
curl -X POST "http://localhost:5000/api/detect" \
    -H "Content-Type: application/json" \
    -d '{
        "text": "Your text to analyze here...",
        "language": "en",
        "detailed": true
    }'

Authentication

REQUIRED FOR PRODUCTION

For production use, API keys are required. Get your API key

With API Key 
curl -X POST "http://localhost:5000/api/detect" \
    -H "Content-Type: application/json" \
    -H "X-API-Key: YOUR_API_KEY_HERE" \
    -d '{"text": "Your text..."}'

Endpoints

3 ENDPOINTS AVAILABLE
POST /api/detect Live

Main endpoint for AI content detection. Accepts text input and returns detailed analysis.

Parameters
text string Required Text content to analyze (min 20 words)
language string Optional Language code (default: "en")
detailed boolean Optional Return detailed analysis (default: true)
POST /api/upload Live

Upload files for analysis. Supports TXT, PDF, DOC, DOCX formats.

File Upload Example 
curl -X POST "http://localhost:5000/api/upload" \
    -H "X-API-Key: YOUR_API_KEY" \
    -F "file=@/path/to/your/document.pdf"
GET /api/health Live

Check API status and service health.

Health Check 
curl -X GET "http://localhost:5000/api/health"

Response Format

JSON

Response Fields
ai_probability float Probability text is AI-generated (0-100)
confidence float Model confidence in prediction (0-100)
is_ai_generated boolean Final verdict based on threshold
model_version string Version of detection model used
sentence_analysis array Sentence-by-sentence analysis
feature_importance array Key features influencing decision
